# Simulador de Crédito Personal

Simulador web de crédito personal con amortización constante, interés sobre saldos insolutos e IVA del 16% sobre intereses.

## Uso

Abre `index.html` en el navegador o despliega en GitHub Pages.

## Despliegue

1. Sube el repo a GitHub
2. Settings → Pages → Branch `main` → Save
